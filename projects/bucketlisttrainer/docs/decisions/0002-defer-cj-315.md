# ADR-0002: Defer C&J 315 to year two, target 295

**Status:** accepted, revisitable in week 1 · 2026-07-28

## Context
Bucket list item is a 315 clean and jerk. Baseline: clean 275, jerk 255.

The jerk sitting **below** the clean is backwards for almost every lifter and indicates
a technical and overhead-confidence limiter rather than a strength one. Reaching 315
requires roughly +60 lb on the jerk and, gating it, a front squat near 350 from a
believed ~275.

Neither gap closes inside one 15-week block, and Block 1 runs a caloric deficit where
strength gain is limited by definition.

## Decision
Target C&J 295 this year. Move 315 to a dedicated first-quarter push in 2028.

## Revisit trigger
Front squat is **untested**. The stated 275 is a guess and it cannot be right, since
almost nobody front squats only what they clean. If the week 1 test returns **315 or
above**, reopen this decision immediately: it would mean the squat gate is largely
already met and only the jerk gap remains.

## Consequences
- Front squat and jerk work start in Block 1 rather than Block 2, buying 28 weeks
  instead of 15.
- Block 2 percentages for the C&J run off the **jerk** max, not the clean, because the
  jerk is the binding constraint.
